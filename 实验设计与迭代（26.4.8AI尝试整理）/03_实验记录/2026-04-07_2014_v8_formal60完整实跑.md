## 6. 这轮结果最该怎么解释

### 6.1 训练骨架通了，但聚合后的执行质量没跟上

`47 / 60` retained 说明 task-local 训练已经能沉淀不少有效局部技能。

但 `flat/tree` 只做到 `15 / 60` 与 `18 / 60`，说明瓶颈主要出在：

- aggregated skill 的注入形态
- executor 的 memory 与长轨迹承载
- 细粒度执行与 answer mapping

### 6.2 `vision` 大簇是最大的拖分项

从旧观察和这轮整体表现看，最值得单独盯住的仍然是：

- `vision` cluster

它题量大，而且执行质量一差就会明显拖垮总体分数。

### 6.3 当时还不能把 `flat` 低分简单归因到“单层设计差”

因为后面的重跑已经证明：

- executor memory 修正后，`flat` 提升幅度很大

所以这轮 `flat` 的低分，只能说是：

- 单层 skill 在当时那版 executor 条件下表现很差

不能直接升格成：

- 单层 skill 天生不行
