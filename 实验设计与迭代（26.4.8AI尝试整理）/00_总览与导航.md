## 5. 这版整理采用的规则

后面如果继续维护，建议坚持下面四条：

1. 一个文件只承担一种职责。
2. `01_当前方案` 只保留当前有效版本，不再开“第 N 部分及后续”。
3. `03_实验记录` 一次 run 一篇，不把不同日期和不同口径的结果混写。
4. `03_实验记录` 文件名统一用 `YYYY-MM-DD_HHMM_事项.md`，时间前缀精确到分钟；非单次 run 的阶段汇总也用分钟位做排序前缀。
5. 机制专题只写稳定认识，run-specific 样本和指标下沉到实验记录。
